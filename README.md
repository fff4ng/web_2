# 🍂 木石之間 Between Woods & Stones

## 📌 專案介紹
「木石之間」是一個以日系侘寂風（Wabi-Sabi）為主題的時令餐飲網站，提供順應自然四季的精緻旬味料理資訊，讓使用者能夠在數位體驗中感受時間的刻痕與大地的饋贈。

本網站以極簡的介面設計與留白美學，呈現春、夏、秋、冬等季節的限定饗宴，並提供詳細的食材故事與套餐介紹，提升使用者的沉浸式感官體驗。未來將提供線上訂位與時令食材曆查詢功能，方便饕客依個人需求預約專屬的季節美味。

---

## 🎯 專案特色

- 🌸 四季時令料理分類（春 ‧ 萌芽 / 夏 ‧ 靜謐 / 秋 ‧ 豐收 / 冬 ‧ 圍爐）
- 🖼️ 雜誌感圖文交錯排版（首頁經典招牌菜自動非對稱排列）
- 🎨 侘寂風色彩與字體計畫（燕麥白、枯茶色搭配優雅襯線體）
- 🧭 導覽列固定置頂設計（方便快速切換各季節頁面）
- 🪟 2x2 季節菜單網格（分頁採用乾淨俐落的 CSS Grid 佈局）

---

## 🗂️ 網站架構
- index.html 首頁（熱門經典菜色）
- spring.html 🌸 春 ‧ 萌芽（春季限定選單）
- summer.html ☀️ 夏 ‧ 靜謐（夏季限定選單）
- autumn.html 🍁 秋 ‧ 豐收（秋季限定選單）
- winter.html ❄️ 冬 ‧ 圍爐（冬季限定選單）
- aboutus.html 關於我們（品牌故事與理念）
